# IPL Match Winner Prediction

## Overview
An interactive machine learning web application that predicts the likely winner of an upcoming IPL match using historical cricket data from the past 15–18 years.

## Technologies Used
- Python
- Pandas and Scikit-learn
- Machine Learning
- Streamlit

## Key Features
- Historical cricket data preprocessing and analysis
- Feature engineering and feature selection
- Comparison of multiple classification models
- Interactive interface for match predictions

## Project Structure
- `app.py` — Main application
- `src/` — Source code
- `reports/` — Project reports and outputs
- `requirements.txt` — Python dependencies

## How to Run
1. Clone the repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the application:
   `streamlit run app.py`

## Disclaimer
Predictions are estimates based on historical data and are not guaranteed match outcomes.
